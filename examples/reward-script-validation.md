# 测试样例：家庭奖励机制

## 输入
很多家庭周末会特意吃顿好的；成年后自己吃饭、购物奖励；想扩展精神、世界观、身体感知；家庭奖励方式可能影响下一代；希望用故事唤起共鸣。

## 通过
- 开头有可感知的周末饭菜或生活场景。
- 不把家庭影响写成决定性因果。
- 能从个人习惯自然推进到家庭/代际。
- 结尾让读者想起自己的周末或奖励方式。
- 若用真人素材，只使用明确授权且符合隐私要求的图片。
- 资讯、心理学或医学判断有证据边界。

## 不通过
- “你们都被原生家庭控制了。”
- “你必须立刻建立六维自我激励体系。”
- 编造用户本人的童年、父母对白或私人冲突。
- 为互动量制造焦虑。
