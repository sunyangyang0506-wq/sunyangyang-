# 人物与现场封面：有主体、有看点、缩小仍清楚

封面先吸引注意，再让读者知道讲什么。选择一个有意义的视觉主体和一句具体主张，不把日报目录、长摘要和全部新闻塞进首图。

## 两种可选风格

两种都可使用，按题材、可用素材和栏目近期封面选择，不强制每日轮换。用户指定时沿用。私人配置可记录 `cover_style: auto / scene-bold / event-documentary`，默认 `auto`。

### A｜人物场景＋醒目大字（scene-bold）

有生活或工作环境的主体、暖色光影、明确景深，配大字和少量亮色强调。动作、表情或道具与内容的问题有关。

- 一个人物、物件或可读操作场景作为主角；不要求本人露脸。背景承担氛围，少放无关道具。
- 主标题一到两行，白字配淡黄等单一强调色，突出一两个关键词；保证文字与背景反差。
- 可用轻微描边、局部阴影、手写箭头或短便签强调问题，避免满屏贴纸。
- 标题与主体错开，不遮脸、手势和关键道具。顶部说明主题，下方短句可补实际收益，不把四边都塞满。
- 教程展示真实操作或成果。研究与新闻可用明确标注的编辑插画，不能伪装成真实患者、专家背书或新闻现场。

制作简报示例：暖色工作场景，一个有关的视觉主体；上方醒目短标题，白字、淡黄关键词；边角一条短问题，边缘留安全区。不要照搬参考人物、服装、品牌和精确构图。

### B｜真实现场＋简洁主题（event-documentary）

保留会议、采访、演讲或活动的真实气氛。清晰的舞台主题，人物与少量环境提供尺度和纵深。大面积红色或其他现场主色形成焦点，不必把所有内容改成红色。

- 优先选择真实、可使用的官方照片或授权现场影像，裁切到主题、人物及必要环境，保留事件上下文。
- 现场文字清楚时可承担主标题；不足以表达本篇切口，再加一条简洁且有证据的编辑标题，不与背景争抢焦点。
- 编辑标题与真实发言区分，不做成舞台原文或伪造引语，不把虚构观点贴到真人身上。
- 人物可以较小，背景主题承担阅读焦点；适量前景增强纵深，不拼贴虚假人群。
- 无真实现场图时，选择 A 的物件/编辑插画方案，或明显属于编辑设计的纯色主题卡。不能生成逼真假发布会冒充现场。

制作简报示例：已核验来源的会议实拍，保留大面积现场主色和清晰主题；人物与环境形成纵深，只加必要短标题和日期。不复制参考品牌标识、姓名或暗示品牌合作。

## 文稿与封面统一

从 [文稿参考](xiaohongshu-alive-writer.md) 取得标题、封面主句、证据和开头承诺，再选画面。发布标题负责主题与检索，封面负责一个视觉焦点，正文尽快给答案，不把同一句长标题抄三遍。

多条简报选一条有价值的主问题做视觉中心，其余重点放短副标题或内页。日期和栏目是辅助信息，不能成为唯一大标题；历史材料有可辨认的“历史进展复核”及日期，不为吸睛淡化时间边界。

内页延续封面色彩和字体层级，不重复封面口号。图表保留口径与来源，信息多就拆页或保留长文，不缩成难读小字。用户要求完整原稿时不删减正文或原图。

## 素材、人物与隐私

使用当前会话、用户文件库或明确授权来源的素材。参考图是风格依据，不自动等于转载权、本人影像或品牌合作授权，不照搬他人肖像和标识。

本人出镜需来自用户确认的真实照片。可轻调曝光、白平衡、裁切和背景，保留五官比例、脸型和年龄感；漫画化也不能把无关角色叫作本人。不自动保存永久人像参考。

新闻人物、授权素材人物和原创示意角色分别标明来源与身份。多人画面保留获准范围，检查屏幕、反射、胸牌与联系方式。用户要求脱敏时，优先用物件、场景或非本人示意，不默认用户出镜。医学与金融题材不使用虚构患者故事、效果对比或名人推荐暗示。

生成或修改图片用当前环境支持的图像工具；中文不清楚就简化文案或使用可靠排版方式，重新检查成品。无生成能力时交付制作简报，不能把方案称作成品。原始素材、制作版本分开保存，不覆盖恢复中的原图。

## 成品验收

图文通常从 3:4 竖版起步，按平台入口适配，并预览信息流裁切。不要把参考截图的账号栏、播放按钮、滚动条或外部边框做进封面。

至少把实际成品缩到约 300 像素宽检查：主句能一眼读到，主题能识别，主体没被文字挡住，数字与必要日期清楚。留边缘空间，避免换行把词和日期拆得难读。

默认制作一个选定风格的成品，用户要求比较时再做两版。记录风格、文案、尺寸、来源/身份依据、版本和必要生成说明。

发布预览首图应为选定封面。平台自动新增纯文字页或模板封面时，用正常封面/排序控件修正并复查，避免设计封面变成第二页的小缩略图；原样同步另有用户要求时按其要求处理。最后由 [发布流程](../SKILL.md) 核对顺序、隐私、授权和回执，已有有效授权沿用。
