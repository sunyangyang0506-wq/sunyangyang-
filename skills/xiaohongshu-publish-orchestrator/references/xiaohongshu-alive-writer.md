# 文稿：先把读者的问题说清楚

有趣来自具体问题、事实反差和可用答案。封面、标题、开头讲同一件事；读者点进来，首段就应得到线索或答案。

## 先分清改动范围

- **新创作或授权改编**：可优化选题、标题、开头和结构，保留事实、条件、来源与不确定性。
- **完整原稿同步**：保留全部内容、原顺序、数据、表格、图注和来源；可以按授权优化发布标题与封面，不把全文删成摘要。要改善内页结构，在下一期生成时处理。
- **个人观察**：只有用户真实提供的经历才能写成“我”。不代用户编造身份、收入、对白、患者故事或情绪。
- **新闻简报**：区分事件日和报道日、历史复核与当天消息、事实和分析；政策支持、获批、上线与订单落地分别表达。

数据驱动的任务先读[数据复盘与改进](content-feedback.md)。已有近期快照时复用，不反复取数；用户的封面参考说明设计偏好，不证明该风格带来了流量。

## 选题与内容生成

先用一句话回答：“给谁看，帮他做什么判断，本文有什么证据？”从材料里选最具体的入口：谁会付钱、哪个流程卡住、一个数字说明什么、下一步查什么。没有事实支撑的冲突不用硬造。

多条简报保留约定栏目与全部条目，主标题只挑一条最有价值的问题。不要强行把所有新闻编成同一因果故事。无当天新进展时明确历史复核，不把旧消息包装成新机会。

产生少量不同切口再选一个：事实与边界、具体操作、读者决策。选择正文能兑现的标题，不只轮换“必看、终于、变天”等形容词。栏目识别靠稳定主题和表达，不能只靠每日日期。

## 封面、标题和首段

| 位置 | 给读者什么 | 写法 |
| --- | --- | --- |
| 封面 | 一眼认出主题和看点 | 一句简单直接的大字，或原文真实图片配短句；细节不堆首图 |
| 发布标题 | 主题＋问题或具体收获 | 重要主题词靠前；自然表达，按实际入口限制适配长度 |
| 正文首段 | 答案、关键证据与阅读价值 | 前两三句进入事实和判断，不先介绍“本期简报聚焦……” |

日期通常放栏目小字或标题末尾，给主题留出前部空间；原稿同步时保留正文日期和标题层级。需要日报识别或同日去重时，私人记录仍保留明确日期与栏目。

可用的标题写法示例，不能当作新事实直接发布：

- `入境医疗的需求，怎么核实？`：正文提供具体核实路径，而不只说市场潜力。
- `医院需求清单里，先看这几件事`：正文确有需求、预算、负责人及验收等检查项。
- `医疗平台上线后，谁来接住患者？`：区分已确认的服务流程和待访谈的问题。

不以疗效、收入和必然趋势作承诺；不借参考图的“千万播放”或“年入千万”替自己的内容背书。不做假引语、假亲历或空悬念。封面制作读[简洁大字与原文图片](personal-visual-storyteller.md)。

## 结构展示：先答案，再证据和行动

新创作可用“结论 → 证据与边界 → 具体行动”。信息多时先给短导读，读者可迅速找到相关章节，不把完整答案藏在十几页之后。

多条新闻每条交代核心事实，再说明与目标读者的关系、仍需核实的内容；必要时用“发生了什么”“意味着什么”“下一步查什么”作小标题。不是每个段落都必须填同样的标签，空泛字段应删除。

内页每页有一个主要信息点，标题有意义，段落以一件事为单位。表格适合真正需要比较的项目；不兼容时按原行带列名展开，保留所有单元格。关键数据保留时间、单位、范围和来源。新稿可合并重复的同一来源入口，但不同来源不静默丢失；原稿同步仍按完整性要求保留。

末尾交付具体可用的内容：检查清单、访谈问题、观察信号或操作步骤。保留完整商业研究行动，不用“看好前景”“建议关注”替代。没有必要不强迫结尾提问，不要求“扣1”“收藏不亏”。

## 风格与文字表达

用自然、准确的中文。先说主体和动作，再解释影响；一句不要堆太多概念。一段解决一件事，长短自然变化，不把每个短句都独立成一行，也不铺成报告式长墙。

| 抽象写法 | 更直接的写法 |
| --- | --- |
| 验证潜在付款方 | 找到谁可能付钱，问清谁有采购权 |
| 形成商业闭环 | 核实需求、预算和验收，再决定是否做产品 |
| 赋能跨境服务能力 | 说出具体改善了预约、支付还是跨院交接 |
| 存在巨大市场空间 | 给出已知需求证据，说明还缺哪些判断依据 |

这些是表达示例，不替代专业名词和事实。保留有用术语并在首次出现时解释；新闻引语与正式文件名称不为口语化而失真。

事实后接有依据的判断：“这说明……”“但还不能证明……”“下一步可核实……”。不把每篇都写成宏大叙事，不用无依据的情绪代替信息。医学或财经新闻解读不写成个人诊疗或投资指令。

## 交付与检查

交付选定标题、封面主句与方式、可复制正文、图文顺序和来源；有数据复盘时另列本次改变了什么、依据、待验证假设与比较口径。原始数据、账号信息和私人分析只存私人目录。

检查首段是否兑现标题、每个数字是否有口径、内容能否帮助读者行动、图表和来源是否完整、日期和隐私是否正确。已提交稿不因新风格自动改动或重发；发布授权、去重与回执由[发布流程](../SKILL.md)处理。
