# 本人出镜视觉内容 Skill

## 日报原图与非人物封面
已有发布包优先验证真实原图字节、尺寸、哈希、顺序和图注，不为换风格重绘或重发已公开稿。新稿可选“场景主体＋白黄大字”或“真实现场＋简洁主题”；真实现场必须有可核实来源和使用权，示意画面标明示意，不伪造新闻现场。人物身份基线只适用于确需呈现用户本人的方案，资讯封面无需强行插入人像，不复制参考人物或品牌。使用当期清单决定图数，封面与原位配图分别核对完整显示、裁切和图注末行。持续授权范围内逐项自检，不重复索要逐次发布确认；只向唯一发布端交付版本化素材及清单。

## 1｜目标
真实性优先于精修，情绪准确优先于戏剧化。

不使用虚构人物冒充用户本人，也不默认每张内容都需要露脸。

## 2｜固定工作流
1. 理解内容：核心观点、目标读者、情绪弧线、视觉钩子。
2. 检查素材访问：仅使用当前会话、用户文件库或明确连接且获授权的素材。
3. 需要呈现本人时建立临时身份基线：必须来自用户明确确认的本人影像；非人物资讯按来源与版权核验。
4. 视觉策划：明确每张图的用途、来源、AI修改方式和风险。
5. 内容制作。
6. 发布前逐项确认：人物、平台、版本、AI编辑说明。
7. 将已核验素材交给目标渠道唯一发布端，由其核验授权、去重、预览与回执。
8. 获得真实数据后再复盘。

## 3｜视觉模式

### A. 真人实拍 + 轻美化
裁切、曝光、白平衡、轻微瑕疵修饰、背景简化、字幕排版。
保留脸型、五官比例、年龄感和现场感。

### B. 本人漫画 / 插画化
必须以真实本人照片为参考。
艺术化可以简化，但不能把无关虚构人物称作本人。

### C. 夸张情绪表达
优先夸张构图、画风和视觉隐喻，而非扭曲真人照片。

### D. 像素 / 马赛克 / 拼贴实验
用于风格时仍以真实影像为基准；用于隐私遮挡时必须真正遮挡有效。

## 4｜推荐规则
- 默认优先真人实拍。
- 同一内容最多组合两种视觉模式。
- 每张图需说明：对应文案、情绪、来源、身份依据、AI编辑说明。
- 封面文字短、清楚、非标题党。

## 5｜人物与隐私
- 多人照片中若只允许本人出镜，必须可靠裁剪或移除其他人物并复核。
- 不根据文本或性格描述猜测长相。
- 不自动把照片保存为永久人像参考。
- 保存长期人像参考需额外明确授权。
- 背景镜面、反射、屏幕和路人同样需要隐私复核。

## 6｜发布门禁
**创作授权不等于上传授权。**

真正对外发布前必须确认：
- 使用哪一版
- 发往哪个账号/平台
- 哪些图片/视频
- 是否包含AI编辑或生成
- 是否存在他人影像/隐私
- 最终预览与待发布版本一致

## 7｜交付模板
1. 创作简报
2. 素材清单
3. 封面候选/图片顺序/视频分镜
4. 审批清单
5. 发布结果（由唯一发布端提供后台审核／公开证据，上传成功不算发布）
